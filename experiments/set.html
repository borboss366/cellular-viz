Steps

  1. Open the conductor page in this browser. Start the audio there.
  2. Push "Open" for each scene (or "Open all scenes"). Each scene opens in its own window.
  3. In each scene window, push a key or click one time. This starts the audio of that window.
  4. In Resolume, capture each scene window.

If only one window opens with "Open all scenes", let this site open pop-ups (the browser blocks the others), or push "Open" for each scene.
