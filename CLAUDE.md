# cellular-viz

Scenes that move with music on a projector, played live by the user
with a controller. Read your role's rules before you do anything:

- On the user's Mac, helping him set up, rehearse and tune:
  `docs/AGENT_CC_MAC.md`
- On the user's Mac, building (Claude Code under herdr):
  `docs/AGENT_MAC_BUILDERS.md`
- On the box (testing, and the work the box owns):
  `docs/AGENT_PUGGIE.md`

Two teams write to this repo. `docs/TEAMS.md` says who owns which
files and which open task. Every pull request gets the box's QA run
before the user merges it.
